# Front-End Rapor Görsel Listesi

Bu klasör, `frontend-staj-raporu.md` dosyasında önerilen ekran görüntüleri ve kod görselleri için ayrılmıştır. Aşağıdaki görseller manuel olarak hazırlanıp bu klasöre kaydedilmelidir.

- `gun-01-dosya-yapisi.png`: Proje içindeki `resources/views`, `resources/css` ve `resources/js` klasörlerini gösteren dosya yapısı görüntüsü alınmalıdır.

## Ek Görsel Notları

- Kod görsellerinde dosya adı ve ilgili satırlar okunabilir şekilde görünmelidir.
- Tarayıcı ekran görüntülerinde sayfanın ana bileşeni tam olarak kadraja alınmalıdır.
- Mobil görünümler için tarayıcı geliştirici araçlarındaki responsive mod kullanılmalıdır.
- Projede ayrı bir footer bileşeni bulunmadığı için footer adıyla ayrı görsel hazırlanmamalıdır.
- Görseller rapora eklendiğinde dosya adları bu README dosyasındaki adlarla aynı tutulmalıdır.
